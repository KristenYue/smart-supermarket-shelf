# AIoT 自动化测试计划

## 测试目标

验证两台智能货架设备从传感器数据生成、MQTT主题与载荷、云端接收、去重排序到远程控制的关键质量属性。自动化测试不依赖真实AWS凭据，可在本地和GitHub Actions中稳定复现。

## 测试范围

| 领域 | 覆盖内容 |
|---|---|
| 遥测契约 | 必填字段、类型、传感器边界、设备白名单、状态枚举 |
| MQTT主题 | 设备命令命名空间、跨设备隔离、非法主题拒绝 |
| 远程控制 | 命令白名单、标准化、ACK设备限制、控制字符拦截 |
| 远程配置 | JSON解析、字段白名单、阈值范围、上下界关系 |
| 故障恢复 | 指数退避、断线后继续上报、设备间状态隔离 |
| 数据一致性 | 重复消息幂等、乱序拒绝、同时间戳冲突检测 |
| 稳定性 | 固定随机种子批量注入重复与乱序消息，核对持久化计数 |

## 分层策略

1. 契约测试：快速验证JSON载荷和MQTT主题。
2. 协议测试：验证幂等、顺序、重连退避和设备隔离。
3. 端到端模拟：在内存网关中验证设备上报到云端读取的一致性。
4. 稳定性场景：批量发送遥测并注入2%重复、1%乱序消息。
5. 实物验证：Arduino、传感器、Wi-Fi、AWS IoT证书和物理执行器需另行执行，不能由本测试替代。

## 通过标准

- 自动化测试全部通过；
- 重复和乱序消息不进入持久化记录；
- 同一设备的相同时间戳不同载荷被识别为冲突；
- 非法设备、非法命令、越权主题和危险配置被拒绝；
- 稳定性场景中持久化数量与`accepted`计数完全一致。
